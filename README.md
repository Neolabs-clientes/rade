# RADE — web del artista

Web de una sola página para **RADE**, rapero de Torrejón de Ardoz (Madrid, 28850) y
mitad del dúo Ocer y Rade. Proyecto de demostración hecho por NEO Labs.

## Contenido

- `index.html` — la web completa (CSS y JS propios).
- `assets/estilo.css`, `assets/estilo2.css` — estilos.
- `assets/fotos/` — fotogramas de sus vídeos y portadas en gran formato.
- `assets/portadas/` — las 45 portadas de su discografía en solitario.
- `assets/audio/` — 27 extractos oficiales de 30 segundos para el reproductor.
- `assets/brand/` — favicon y logotipo.
- `aviso-legal.html`, `politica-privacidad.html`, `politica-cookies.html` — legales.
- `og.jpg` — imagen para compartir el enlace.

## Datos verificados

Proyecto en solitario desde 2023: **28 referencias**, el álbum «El Brillo» (20 cortes,
noviembre de 2025), el EP «Contigo» (5 cortes, junio de 2026) y el single «En Picado»
(julio de 2026). Con Ocer y Rade: **374.000 suscriptores** en YouTube y **117 millones
de reproducciones** sumadas en sus vídeos más vistos.

Todos los enlaces a plataformas y las cifras están comprobados en sus perfiles
oficiales. Los textos legales están pendientes de los datos fiscales del titular.
